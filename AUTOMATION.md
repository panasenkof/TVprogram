Следуй skill в этом репозитории: `.cursor/skills/tv-programma/SKILL.md` и `AGENTS.md`.

Скрипты уже в репозитории: `scripts/measure.py`, `scripts/render.js`. Не ищи skill в домашней папке облачного агента — его там нет.

Собери телепрограмму для Ростова-на-Дону на СЛЕДУЮЩУЮ неделю (понедельник–воскресенье после ближайшего воскресенья, если запуск в воскресенье — на неделю, которая начинается завтра).

1. Скачай данные с https://prov-telegraf.ru/teleprogramma/ — отдельная страница на каждый день. Не выдумывай передачи.
2. Сверь с https://tv.yandex.ru/39 (Ростов-на-Дону). Для полной сетки открывай каждый из 15 каналов на нужный день. При конфликте времени или названия бери Яндекс. Для «Россия 1» бери блок «Россия 1-Дон», пустой федеральный «Россия 1» игнорируй.
3. Собери итоговый `nedelya.txt` по формату из skill (15 каналов, без Карусели/Пятницы/Спаса/Муз-ТВ/Че!).
4. `python3 scripts/measure.py nedelya.txt 12 2 0 layout.json`
5. `npm install` если нужно, затем `node scripts/render.js layout.json programma.docx`
6. `soffice --headless --convert-to pdf programma.docx` (или `libreoffice`). Не используй `/mnt/skills/public/docx/...`.
7. Проверь: около 28 страниц, нет пустых листов и оборванных блоков каналов.
8. Через MCP yadisk загрузи оба файла в `/Телепрограмма/` как `programma-ГГГГ-ММ-ДД.docx` и `programma-ГГГГ-ММ-ДД.pdf` (дата — понедельник собранной недели).
9. Если день недоступен на обоих источниках — собери неделю без него и напиши об этом. Не придумывай сетку.

Не переносить из источника описания передач — только время, название и возрастной ценз.
