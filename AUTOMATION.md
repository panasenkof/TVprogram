Следуй skill в этом репозитории: `.cursor/skills/tv-programma/SKILL.md` и `AGENTS.md`.

Скрипты уже в репозитории: `scripts/measure.py`, `scripts/render.js`. Не ищи skill в домашней папке облачного агента — его там нет.

Собери телепрограмму на СЛЕДУЮЩУЮ неделю (понедельник–воскресенье после ближайшего воскресенья, если запуск в воскресенье — на неделю, которая начинается завтра).

1. Скачай данные с https://prov-telegraf.ru/teleprogramma/ — отдельная страница на каждый день. Не выдумывай передачи.
2. Собери `nedelya.txt` по формату из skill (15 федеральных каналов, без региональных).
3. `python3 scripts/measure.py nedelya.txt 12 2 0 layout.json`
4. `npm install` если нужно, затем `node scripts/render.js layout.json programma.docx`
5. `soffice --headless --convert-to pdf programma.docx` (или `libreoffice`). Не используй `/mnt/skills/public/docx/...`.
6. Проверь: около 28 страниц, нет пустых листов и оборванных блоков каналов.
7. Через MCP yadisk загрузи оба файла в `/Телепрограмма/` как `programma-ГГГГ-ММ-ДД.docx` и `programma-ГГГГ-ММ-ДД.pdf` (дата — понедельник собранной недели).
8. Если день недоступен — собери неделю без него и напиши об этом. Не придумывай сетку.

Не переносить из источника описания передач — только время, название и возрастной ценз.
