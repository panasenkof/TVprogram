# Телепрограмма на неделю

Скрипты лежат в корне репозитория: `scripts/measure.py`, `scripts/render.js`.
Рабочая директория — корень репозитория.

## Что на выходе

Один DOCX и один PDF на всю неделю. Книжная A4, две колонки, Arial 12 pt,
названия каналов 16 pt, между колонками вертикальная линейка.
Каждый день начинается с новой страницы. Примерно 4 листа в день, 28 на неделю.

Жёсткое правило вёрстки: **блок канала никогда не разрывается** — ни между
колонками, ни между страницами. Ради этого порядок каналов внутри дня
переставляется упаковщиком.

## Параметры (зафиксированы, не менять без запроса)

- Каналы: 15 федеральных в порядке значимости — Первый канал, Россия 1, НТВ, ТНТ, СТС,
  Пятый, РЕН ТВ, Матч ТВ, ТВ Центр, Домашний, ТВ-3, Звезда, Россия К, Мир, ОТР.
- Исключены: Россия 24, Муз-ТВ, Карусель, Пятница!, Спас.
- Окно эфира: 06:00–01:00. Ночь отбрасывается.
- Граница вещательных суток 04:30: время раньше неё относится к предыдущему дню.
- Кегль 12 pt, 2 колонки, книжная. При других значениях условие неразрывности
  блоков не выполняется — проверено перебором.

## Порядок работы

### 1. Собрать исходник

Источник — `https://prov-telegraf.ru/teleprogramma/`, отдельная страница на каждый день
недели (понедельник–воскресенье). Страницы публикуются заранее, поэтому
в воскресенье вся следующая неделя обычно уже доступна.

Данные там в сжатом газетном виде: одна строка на передачу, повторы перечислены
через запятую. Перенести их в файл `nedelya.txt`:

```
# Среда, 2 сентября 2026
== Первый канал
05.00, 07.50 «Доброе утро» (0+)
09.00, 12.00, 15.00, 18.00, 03.00 Новости (16+)
== Россия 1
05.00 «Утро России» (16+)
```

- `# ` — заголовок дня, `== ` — название канала.
- Строка передачи: времена через запятую, пробел, название.
- Времена разворачивать не нужно, это делает скрипт.
- Названия каналов писать ровно так, как в списке выше, иначе исключения
  и порядок значимости не сработают.
- Отдельные региональные каналы (Первый Ростовский и т.п.) не включать.
  Исключение: сетка **Россия 1-Дон** с Яндекса — это местный эфир «России 1»
  для Ростова-на-Дону; писать её под заголовком `== Россия 1`.

### 2. Сверить с Яндекс.Телепрограммой (Ростов-на-Дону)

Второй источник, **приоритетный при конфликте**:
`https://tv.yandex.ru/39` (регион 39 — Ростов-на-Дону).

Не открывать общий `tv.yandex.ru` без `/39` — там будет другая сетка.

Сводка города часто показывает только «сейчас / ближайшее». Для полной
суточной сетки открыть **каждый из 15 каналов** на нужный день (вкладки дат
на странице канала). Неделя вперёд на Яндексе обычно уже есть.

Сопоставление имён (в `nedelya.txt` писать правый столбец):

| Яндекс              | В файле          |
|---------------------|------------------|
| Первый              | Первый канал     |
| Россия 1-Дон        | Россия 1         |
| НТВ                 | НТВ              |
| ТНТ                 | ТНТ              |
| СТС                 | СТС              |
| Пятый канал         | Пятый            |
| РЕН ТВ              | РЕН ТВ           |
| Матч!               | Матч ТВ          |
| ТВ Центр            | ТВ Центр         |
| Домашний            | Домашний         |
| ТВ-3                | ТВ-3             |
| Звезда              | Звезда           |
| Культура            | Россия К         |
| МИР / Мир           | Мир              |
| ОТР                 | ОТР              |

Пустой федеральный блок «Россия 1» на Яндексе игнорировать — брать **Россия 1-Дон**.
По-прежнему не включать: Россия 24, Муз-ТВ, Карусель, Пятница!, Спас, Че!.

Правила сверки по каждому каналу и дню:

1. **Конфликт** (то же время ±1 мин, другое название или другой слот у той же
   передачи) — брать **Яндекс**: время и название.
2. Слот есть только на Яндексе — добавить.
3. Слот есть только у Telegraf, а у Яндекса на этот день по каналу полная сетка
   без этого времени — **выбросить слот Telegraf** (Яндекс главнее).
   Если у Яндекса за день пусто или явная дыра — слот Telegraf оставить
   и отметить в отчёте.
4. Возрастной ценз: Яндекс его часто не даёт. Если название совпало —
   сохранить ценз из Telegraf. Не выдумывать ценз.
5. Описания передач с Яндекса не копировать — только время, название, ценз.
   Длинные яндексовские названия можно слегка сжать до газетного вида
   (сезон/серии оставить), смысл не менять.

После сверки итоговый `nedelya.txt` — это уже ростовская сетка.

### 3. Посчитать раскладку

```bash
python3 scripts/measure.py nedelya.txt 12 2 0 layout.json
```

Аргументы: файл, кегль, число колонок, альбомная (0/1), выходной JSON.
Скрипт меряет ширину строк по метрикам Liberation Sans (совместим с Arial),
разбивает переносы, считает высоту каждого блока и раскладывает блоки
по колонкам методом first-fit-decreasing.

Если в выводе появилась строка «не влезает в колонку» — какой-то блок выше
колонки. Не игнорировать: либо уменьшить кегль, либо сузить окно эфира.

### 4. Собрать файлы

```bash
npm install
node scripts/render.js layout.json programma.docx
soffice --headless --convert-to pdf programma.docx
```

Если `soffice` нет в PATH, попробуйте `libreoffice`. Не используйте путь
`/mnt/skills/public/docx/...` — его в этой среде нет.

### 5. Проверить перед выдачей

```bash
pdfinfo programma.pdf | grep Pages
```

Ожидаемо около 28 страниц на неделю. Отрендерить две-три страницы
(`pdftoppm -jpeg -r 80 programma.pdf p`) и убедиться, что нет пустых листов
и оборванных блоков.

### 6. Загрузить на Яндекс.Диск

Через MCP `yadisk` загрузить оба файла в папку `/Телепрограмма/`.
Имена: `programma-ГГГГ-ММ-ДД.docx` и `programma-ГГГГ-ММ-ДД.pdf`,
где дата — понедельник собранной недели.

## Зависимости

`docx` (npm), `fonttools` (pip), пакет шрифтов Liberation, LibreOffice для PDF.

## Чего не делать

- Не восстанавливать программу по памяти. Если страницу за какой-то день
  достать не удалось — сказать об этом и собрать неделю без него,
  а не придумывать сетку.
- Не переносить из источника описания передач: это авторский текст.
  Брать только факты — время, название, возрастной ценз.
