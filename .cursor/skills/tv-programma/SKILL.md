# Телепрограмма на неделю

Скрипты в корне репозитория: `scripts/build_week.py`, `scripts/grouping.py`,
`scripts/measure.py`, `scripts/render.js`.
Рабочая директория — корень репозитория.

## Что на выходе

Один DOCX и один PDF на всю неделю. Книжная A4, две колонки, Arial 12 pt,
названия каналов 16 pt, между колонками вертикальная линейка.
Каждый день начинается с новой страницы. Обычно 5–6 листов в день, **около 40
на неделю** (не 28: блоки каналов не рвутся, поэтому плотнее 4 листов/день
не складывается).

Жёсткое правило вёрстки: **блок канала никогда не разрывается** — ни между
колонками, ни между страницами. Ради этого порядок каналов внутри дня
переставляется упаковщиком.

Текст колонок не вплотную к вертикальной линейке: внутренний отступ ячейки
~7 pt с обеих сторон.

Одинаковые по названию передачи **склеиваются в одну строку**. Времена начала
через запятую (`09:00, 12:00, 15:00 Новости`). Если слоты идут подряд —
диапазон от начала первого до начала следующей *другой* передачи
(`06:00–07:00 Мультфильмы`). Это делает `scripts/grouping.py` и при сборке
сетки, и при вёрстке.

## Параметры (зафиксированы, не менять без запроса)

- Каналы: 15 федеральных в порядке значимости — Первый канал, Россия 1, НТВ, ТНТ, СТС,
  Пятый, РЕН ТВ, Матч ТВ, ТВ Центр, Домашний, ТВ-3, Звезда, Россия К, Мир, ОТР.
- Исключены: Россия 24, Муз-ТВ, Карусель, Пятница!, Спас.
- Окно эфира: 06:00–01:00. Ночь отбрасывается.
- Граница вещательных суток 04:30: время раньше неё относится к предыдущему дню.
- Кегль 12 pt, 2 колонки, книжная.

## Порядок работы

**Не скачивай HTML источников в чат и не собирай `nedelya.txt` вручную.**
Сетку пишет `scripts/build_week.py` (Телеграф + Яндекс ТВ Ростов, при конфликте — Яндекс,
для «Россия 1» берёт «Россия 1-Дон»). В контекст модели попадает только короткий отчёт.

### 1. Скачать и сверить сетку

```bash
python3 scripts/build_week.py
```

Пишет `nedelya.txt` и `build-report.json`, печатает неделю, fallback и пропуски.
По умолчанию цель — **следующая** неделя (пн–вс после ближайшего воскресенья;
если сегодня воскресенье — неделя с завтрашнего понедельника). Если на неё нет
страниц в индексе Телеграфа, скрипт **не** опрашивает Яндекс на 7–13 дней вперёд
и собирает текущую неделю.

Читай только stdout / `build-report.json`. Если `missing_days` не пустой —
собери без этих дней и напиши об этом. Не выдумывай передачи.

### 2. Раскладка и файлы

```bash
python3 scripts/measure.py nedelya.txt 12 2 0 layout.json
node scripts/render.js layout.json programma.docx
soffice --headless --convert-to pdf programma.docx
pdfinfo programma.pdf | grep Pages
```

`npm install` — только если нет `node_modules`. Если `soffice` нет в PATH —
`libreoffice`. Не использовать `/mnt/skills/public/docx/...`.
`scripts/grouping.py` отдельно не запускай: его импортируют `build_week.py` и `measure.py`.

Если в выводе measure есть «не влезает в колонку» — не игнорировать.

Ожидаемо **около 40 страниц**. Две-три страницы через
`pdftoppm -jpeg -r 80 programma.pdf p` — нет пустых листов и оборванных блоков.

### 3. Загрузить на Яндекс.Диск

Через MCP `yadisk` в `/Панасенко/Телепрограмма/`:
`programma-ГГГГ-ММ-ДД.docx` и `.pdf` (дата — понедельник собранной недели,
поле `monday` в отчёте). Папки `/Телепрограмма/` в корне Диска нет.

### 4. Уведомить в Telegram итоговым отчётом

Это **последний шаг**, после загрузки (или сразу, если сборка сломалась).

Сформулируй **тот же краткий итоговый отчёт**, который пишешь в конце запуска
автоматизации — не однострочник «готово». В отчёт включи:

- статус: успех / частично / ошибка
- какая неделя (даты пн–вс, поле `monday`)
- куда залиты файлы (`/Панасенко/Телепрограмма/`, имена docx и pdf)
- число страниц PDF
- `missing_days` и fallback на текущую неделю, если были
- что пошло не так, если не всё удалось

Текст отчёта отправь через stdin (не через аргумент командной строки — ломает переносы):

```bash
python3 scripts/notify-telegram.py <<'EOF'
…весь краткий отчёт…
EOF
```

Токен и chat_id только из `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
Не печатать секреты, не подставлять их в команду, не коммитить.
Если переменных нет — не падать всей сборкой, отметить в отчёте запуска,
что Telegram не ушёл.

## Зависимости

`docx` (npm), `fonttools` (pip), Liberation, LibreOffice.

## Чего не делать

- Не восстанавливать программу по памяти и не открывать в браузере все 15×7
  страниц Яндекса — это делает скрипт.
- Не переносить описания передач и возрастной ценз: только время и название.
